# Receipt Pro V2 - النسخة المرتبة

هذه النسخة تحافظ على نفس تصميم ووظائف V2.2، لكن تم ترتيب المشروع ليسهل تعديله مستقبلًا.

## تشغيل المشروع
افتح `index.html` في المتصفح.

## أين أعدل؟

- تغيير الألوان، حجم الخط، الأزرار، القائمة الجانبية، الوضع الليلي: `css/global.css`
- تصميم لوحة التحكم فقط: `css/pages/dashboard.css`
- تصميم الحسابات: `css/pages/accounts.css`
- تصميم السندات والطباعة والفلاتر: `css/pages/receipts.css`
- تصميم التقارير: `css/pages/reports.css`
- تصميم تسجيل الدخول: `css/pages/auth.css`

## ملفات JavaScript

- البيانات والحسابات والأرصدة والسندات والتحويلات: `js/core/storage.js`
- القائمة الجانبية، الشريط العلوي، Toast، Modal، Excel: `js/core/app.js`
- كل صفحة لها ملف داخل `js/pages/`

## قاعدة مهمة
لا تضع كود JavaScript داخل HTML. إذا أردت إضافة ميزة لصفحة، ضعها في ملف الصفحة داخل `js/pages/`.

اقرأ أيضًا: `docs/PROJECT_GUIDE_AR.md`

## تحديث V2.4 — فصل المستخدمين
- كل مستخدم له حساباته المالية الخاصة به فقط.
- كل مستخدم له سنداته وتحويلاته وعملاؤه وإعدادات الشركة الخاصة به.
- إنشاء مستخدم جديد يبدأ برصيد صفر وبدون حسابات مالية جاهزة.
- تسجيل الخروج لا يحذف المستخدم أو بياناته.
- البيانات القديمة من V2.3 يتم نقلها تلقائيًا إلى المستخدم القديم عند أول تشغيل.
- حذف الحساب المالي متاح حتى لو عليه حركات؛ تبقى الحركات كسجل تاريخي باسم الحساب المحذوف.
